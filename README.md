## 👨‍💻 Sobre mí

Soy un futuro ingeniero de sistemas apasionado por construir soluciones backend robustas y escalables. Me enfoco en el ecosistema Java con Spring Boot, diseño de APIs REST y gestión de bases de datos relacionales. También disfruto del desarrollo fullstack, construyendo e-commerces y apps web con Next.js. Siempre en búsqueda de aprender nuevas tecnologías y buenas prácticas de desarrollo.

- 🎓 Estudiando **Ingeniería de Sistemas**
- 🔭 Actualmente profundizando en **arquitecturas backend con Spring Boot y Next.js**
- 🌱 Aprendiendo sobre **Docker, microservicios y APIs REST**
- 💡 Interesado en **Clean Architecture y patrones de diseño**
- 🐧 Usuario de **Linux** en el día a día
